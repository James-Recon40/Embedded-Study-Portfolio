# Embedded Pepper Dryer Project

## Project Overview

This project is a portfolio project for practicing embedded system development.

The main goal of this project is to design and implement a basic control system for a pepper dryer using embedded C programming.

This project will be developed step by step, starting from basic control logic and later expanding to hardware-based implementation.

## Project Goals

- Understand the basic structure of an embedded control system
- Practice C programming for embedded applications
- Design simple control logic for temperature, fan, and drying operation
- Document the development process as a portfolio project

## Planned Features

- Temperature monitoring
- Heater control
- Fan control
- Drying time control
- Safety logic for abnormal temperature conditions

## Development Status

This project is currently in the planning stage.

The source code, circuit information, test results, and project images will be added as the project progresses.
