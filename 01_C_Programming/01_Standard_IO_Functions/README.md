# Standard Input and Output Functions

This practice file contains examples of standard input and output functions in C.

## Purpose

The purpose of this practice is to understand how to receive and output characters using `getchar()` and `putchar()`.

## Development Environment

- Language: C
- IDE: Visual Studio
- OS: Windows

## Main Concepts

- `getchar()`
- `putchar()`
- Character input and output
- `while` loop
- Character comparison
- Simple character replacement

## Practice Summary

This source file includes three short examples.

- Example 1: Receive one character using `getchar()` and print it using `putchar()`
- Example 2: Receive characters repeatedly until the Enter key is pressed
- Example 3: Replace `f` or `F` with `X`, and replace numeric characters with `*`

## Source Code

- `standard_io_functions.c`

## Note

The examples are written in one source file because each example is short.

When testing a specific example, the other examples can be commented out.
