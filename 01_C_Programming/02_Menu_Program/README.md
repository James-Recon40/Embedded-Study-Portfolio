# Menu Program Practice

This practice file contains a simple menu-based program written in C.

## Purpose

The purpose of this practice is to understand how to create a menu program, process user input, and separate program logic into functions.

## Development Environment

- Language: C
- IDE: Visual Studio
- OS: Windows

## Main Concepts

- Function declaration and definition
- `while` loop
- `switch` statement
- `getchar()`
- `scanf()`
- Input validation
- Input buffer handling
- `exit()` function

## Practice Summary

This program displays a menu and allows the user to choose one of several options.

Menu options:

- `a`: Print an Avengers message
- `b`: Make a beep sound
- `c`: Count numbers from 1 to the input integer
- `q`: Quit the program

The program also checks whether the user input is valid and asks the user to try again when an invalid menu option is entered.

## What I Practiced

- How to create a simple text-based menu program
- How to use functions to divide program logic
- How to handle character input using `getchar()`
- How to validate integer input using `scanf()`
- How to clear remaining characters from the input buffer
